# Guides

## Administrator guide (Super Admin or assigned administrator)

**Everything on the public website is editable** — no developer needed.

| I want to… | Go to |
|---|---|
| Change the logo, founder pictures, hero, social image, signature/seal | Admin → **Logo & pictures** |
| Edit homepage text, About, Vision/Mission/Values, Founder, Leadership, Admissions page, Fivefold, Ministry Formation, Technology Hub, Kingdom Enterprise, Contact, menu | Admin → **Website content** (every block has version history and "restore default") |
| Put an announcement in the **animated carousel** | Website content → *Homepage carousel* (add slides with pictures/links) **or** News, events & FAQs → create an Announcement/Event and tick *Show in homepage carousel* |
| Publish news, events, announcements, FAQs | Admin → **News, events & FAQs** (Draft → Review → Approved → Published; publishing needs `content.publish`) |
| Add or edit a programme, its objectives, requirements, fees, structure | Admin → **Programmes** (then *Course structure*). Publishing needs Academic Board approval (`curriculum.approve`) |
| Add or edit courses, syllabus, credits, prerequisites, weights, lessons | Admin → **Courses & lessons** |
| Add a department, campus, level (e.g. a new "Master's" level) | Admin → Departments / Campuses & centres / Programme levels |
| Open the semester, set registration & exam dates, assign lecturers | Academic sessions / Semesters / **Course offerings** |
| Change grading scale, credits, standing rules, admissions rules, certificate wording | Admin → **Settings** (each change is validated and audited; give a reason) |
| Create staff, assign roles, edit role permissions | **Faculty & staff**, **Roles & permissions** (Super Admin only) |
| Record payments / invoices | **Finance** |
| Edit the Statement of Faith or policies | **Policies & doctrine** — saves a *new version* for approval; the old version is kept |
| Export a report | **Reports** → Export CSV |
| See who changed what | **Audit & security** |

**Admissions**: Applications → open an application → verify documents → move to *Under review* / *Interview required* → decide (reason required) → after the applicant accepts the offer, **Register as student**.
**Results**: lecturers calculate and submit; HOD/Dean reviews; Registrar/Exam Officer approves and publishes (never the same person who submitted).
**Graduation**: Graduation → *Eligible candidates* → Recommend → a *different* Board member approves → Complete graduation → Issue certificate. Transcripts are drafted from a student's page, approved by one officer and issued by another.
First-time checklist: (1) create Super Admin and enrol 2FA, (2) replace Leadership placeholders, address and contacts (Settings → Institution), (3) set the current session/semester, (4) create staff and assign roles, (5) review and publish the Statement of Faith and policies, (6) open course offerings and assign lecturers, (7) review programme fees and the recognition statement.

## Faculty guide (`/teach`)
My courses → open a course: create assessments (assignments, tests, quizzes, **examinations** drawn at random from the *approved* question bank), publish, grade submissions (AI-use disclosures are shown), take attendance, **Calculate results**, adjust components (e.g. practical), **Submit for review**. Add questions in the *Question bank* (needs approval by another person). Mentors: *My mentees* shows only reflections students chose to share. Lecturer lessons are labelled *Lecturer material*; official doctrine is published only through approved channels.

## Student guide (`/student`)
Apply → track status → accept offer → you become a student. **My courses**: register within the window (prerequisites, credit limits and your programme are checked automatically). Read lessons (works on a phone; text-first for low data), mark complete, submit assignments (declare AI use if you used it), take timed examinations (answers autosave; the server clock decides the deadline). **Results & GPA** show only published results; you can appeal. **Ministry** (log verified practicum hours) and **Spiritual formation** (private journal; share with your mentor if you wish). **Library**, **Technology Hub**, **Kingdom Enterprise**. **Transcript & certificate** shows graduation readiness and downloadable PDFs with a QR code anyone can scan to verify.
